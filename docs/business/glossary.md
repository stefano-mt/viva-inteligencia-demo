# Glosario comercial

| Término | Significado en la demo |
|---|---|
| Proyecto observado | Registro público capturado en la fecha de corte. |
| Proyecto comparable | Proyecto incluido por alcance geográfico y reglas básicas de producto. |
| Precio utilizable | Referencia que supera las reglas de semántica, pairing y calidad. |
| Orientativo | Dato útil para explorar, pero insuficiente para una conclusión certificada. |
| Certificado | Dato con semántica y evidencia suficientes según la policy del snapshot. |
| Cuadrante | Partición analítica basada en coordenadas; no es una división oficial. |
| Evidencia autorizada | Fragmento o activo que puede mostrarse en la demo según el manifiesto. |
| Snapshot | Foto inmutable y validada del dataset utilizado por una versión. |
| Fecha de corte | Momento hasta el cual la demo puede sostener sus afirmaciones. |
| Señal | Cambio entre observaciones; no implica causalidad. |
