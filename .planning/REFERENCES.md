## Síntesis aplicada

- GSD aporta fases, contexto fresco, artefactos Markdown y gates.
- Loop Engineering aporta automación, worktrees, skills/connectores, separación maker/checker y memoria externa.
- Claude Code aporta explore → plan → implement → commit, verificación explícita y aislamiento por worktree.
- Codex aporta plan-first, tareas tipo issue, `AGENTS.md` persistente y delegación explícita.
- Graphify aporta orientación y análisis de impacto, con límites claros frente a verificación.
