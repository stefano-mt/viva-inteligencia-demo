# Archivo de planificación

`.planning` conserva la memoria resumida de las fases 0–8, pero ya no es el punto de entrada del producto. La documentación vigente vive en `docs/`.

Las evidencias binarias de las fases anteriores fueron retiradas del árbol activo para reducir la clonación. Se preservan sin pérdida en la etiqueta Git `demo-static-v1` y en el historial existente. Los nuevos resultados de prueba se publican como artefactos efímeros de CI y no se versionan.
